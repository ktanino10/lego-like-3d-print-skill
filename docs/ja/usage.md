# 使い方：小さく試し、同じデータでつなぐ

[English](../en/usage.md) · [導入](install.md) · [基準資料](../../.github/skills/lego-like-3d-print/references/baseline.ja.md)

<a id="first-request"></a>
## 最初の依頼例

```text
lego-like-3d-printを使って、猫を8 mmピッチのブロック風卓上模型にして。
1作品1案、無接着で分割・組立する形。保存先はこのプロジェクト。
まず外形案、嵌合試験1組と本番の2×2・2×4代表部品を作って。
実FreeCAD形状と同じメッシュでCGと組立説明を作り、
未作成・NOT_SLICED・物理未確認を区別して。公開もプリンターへの送信もしないで。
```

題材、用途・大きさ、分割か一体か、銘板、保存先・公開範囲を伝えます。
全部指定する必要はなく、設計を左右する不足だけをAIが確認します。
「全部まとめて」は一体造形か、別部品を同じプレートへ置くかを区別してください。
新規デザインのコードや形状はAIがそのプロジェクトで作るもので、本スキルに生成器は入っていません。

<a id="workflow"></a>
## 何を受け取るか

| 段階 | 期待する成果物と判断 |
| --- | --- |
| 仕様とデータ | revision、寸法、型ID、色、数量、instance、位置・回転、接続・工程 |
| 実設計 | 妥当なFreeCADソリッド、再openできるFCStd、STEP、mmで扱うSTL |
| 印刷キット | 独立部品の形状3MF、少量試験片、型色別BOM、印刷姿勢と説明 |
| 組立 | 番号付き工程、差込方向、必要部品、印刷slotとの対応、図面/PDF |
| 見た目 | 同じメッシュ・配置のBlender CG、`.blend`、要求した組立MP4 |
| 3D/公開 | 要求した対話ガイド・オフラインZIP、承認済みの場合のみ公開サイト |

「設計だけ」「動画不要」「公開しない」などの範囲を優先します。
CGだけの文字・接合部や、継ぎ目を描いただけの一体模型を組立キットと呼びません。
BlenderやFreeCADが使えない場合は未作成と報告し、拡張子変更で偽装しません。

<a id="mapping"></a>
## 刷った部品から、置く場所まで

`印刷ファイル → slot → 型ID＋色 → 組立instance → 工程・位置・向き`

同形同色なら交換可能なので、取り出せる全プレートと置ける全候補を示します。
印刷順と組立順は違います。台座の段数とプレート番号も違います。
Bだけの例では`B-black-02.3mf` slot 3 → `B-001`、全5段台座には黒01〜04の該当部品が必要です。
新作へBのファイル名・150個・28工程を固定で貼らず、実データから作り直します。

<a id="trial-gates"></a>
## 全数の前に、少量試作

1. ゆるい嵌合試験1組。文字・溝があれば小試験片も。
2. 本番形状の2×2・2×4などを少数。couponだけの成功で進めない。
3. 台座・前面。全幅の反り、整列、保持、交換を確認。
4. 残りの顔・本体。材料・色・ノズル変更時も再確認。

実slicerで、下面開口、初層入口、ブリッジ、薄壁、文字、brimを確認します。
形状3MFは**NOT_SLICED**で、P1S設定やPause入りprojectではありません。
STLはmm・100%で読み込み、同じ部品のSTLと3MFを二重に入れません。
閉塞、着座しない、強い力、白化・割れ、保持不足があれば停止します。
デジタル検査で、物理嵌合・強度・転倒を合格にしません。Send/Printは自動実行しません。

<a id="changes"></a>
## 改良・サイズ変更の依頼

```text
この模型の白文字だけを読みやすくしたい。
黒支持体と取付け、本体は変えず、文字の孔・開口・字間・正の線幅を確認して。
変更部品、旧新版の識別、再印刷する範囲と小さな文字試験片を出して。
```

Bの文字基準は黒2.4 mm＋白1.2 mm、全142×40×3.6 mm、下段ink高さ10 mmです。
白0.8→1.2の0.4増で完成奥行きだけ79.8→80.2となり、黒台座は79.8のままです。
文字は黒z=2.4、ロゴは黒z=2.8の終了後、最初の白経路前に色替えします。
固定層番号・未検証G-codeを作りません。

```text
同じ8 mmピッチ・ブロック形状のまま、机に収まるよう横幅を小さくして。
完成STL全体は縮小せず、ブロック数と配置を変えて。
BOM、工程、印刷プレート、CG、3Dガイドも同じ改訂データから更新して。
```

<a id="publication"></a>
## 公開を頼むとき

公開先のowner/repo、visibility、載せる内容・写真の許可を明確に伝えます。
その作品用に生成した資料だけを公開し、参照元の画像や私有データをコピーしません。
過去の公開許可は別の作品・サービスへの許可ではありません。
mainへの反映だけでなく、Pages実URL、repo-subpath、download、PC/スマホの表示まで確認します。

完成時は、実ファイル・URL、寸法・個数、最初に試すファイル、未作成・未実行・物理未確認を受け取ります。
詳細は[制作手順](../../.github/skills/lego-like-3d-print/references/workflow.ja.md)と[注意事項](notices.md)にあります。
